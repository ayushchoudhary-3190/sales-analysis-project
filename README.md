# sales-analysis-project
sales analysis dashboard
=======
An end-to-end retail sales data analysis project focused on cleaning, processing, and analyzing transactional sales data to identify revenue trends, product performance, category-wise sales, regional performance, and customer purchasing patterns using Python (Pandas), PostgreSQL, Excel, and Power BI. The project includes data quality checks, exploratory data analysis, SQL-based reporting, and an interactive business intelligence dashboard.
